Thought Catcher

Say a thought; it gets sorted into ideas, tasks, journal and reminders. Version 2.0.0.

Install on iPhone

  1. Open this page in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Open it from the new icon.

Install on Android

  1. Open this page in Chrome.
  2. Tap the menu, then Install app.
  3. Open it from the new icon.

Privacy

  1. Thoughts stay on this phone. No account.
  2. The assistant model downloads once, after you agree, and runs here.
  3. Speech: on this phone, or Apple's or Google's service if you pick it.
  4. Your own key sends the text you file to that provider only.
